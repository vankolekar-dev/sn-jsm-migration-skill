# 🔄 ServiceNow → JSM Migration Skill

A **Rovo Dev / Rovo CLI skill** for Atlassian PS Consultants to migrate ServiceNow workflows, automations, and request types to Jira Service Management (JSM).

## ✨ What It Does

| Step | What Rovo Dev Does | Method |
|------|-------------------|--------|
| 1️⃣ Parse | Reads ServiceNow XML export (Flow Designer, Update Set, Catalog) | Automatic |
| 2️⃣ Analyze | Extracts workflows, automations, request types, fields | Automatic |
| 3️⃣ Guide | Generates step-by-step workflow creation guide for Jira UI | Script output |
| 4️⃣ Create | Creates request types and custom fields via JSM API | Automatic (API) |
| 5️⃣ Generate | Produces automation import JSON for Jira UI import | Automatic |

## 🚀 Quick Install

```bash
curl -sSL https://raw.githubusercontent.com/vankolekar-dev/sn-jsm-migration-skill/main/install.sh | bash
```

Then restart your Rovo CLI session — the skill loads automatically.

## 📋 Requirements

- Python 3.8+
- [Rovo CLI (`acli`)](https://developer.atlassian.com/cloud/rovo/rovo-cli/) OR RoHub desktop app
- JSM Admin API token for target instance
- ServiceNow XML export file

## 🎯 Usage

### Via Rovo Dev (conversational)
```
"I have a ServiceNow XML export at /path/to/export.xml. 
 Migrate it to JSM project ITO on https://customer.atlassian.net"
```

### Via Script (direct)
```bash
# Full migration with interactive prompts
python3 ~/.rovodev/skills/jsm-workflow-builder/scripts/sn_to_jsm.py \
  --input export.xml \
  --site https://your-instance.atlassian.net \
  --email admin@company.com \
  --token YOUR_API_TOKEN \
  --project PROJ-KEY

# Workflow guide only (no API calls)
python3 ~/.rovodev/skills/jsm-workflow-builder/scripts/sn_to_jsm.py \
  --input export.xml \
  --workflow-guide /tmp/workflow_guide.md

# Dry run (preview without creating anything)  
python3 ~/.rovodev/skills/jsm-workflow-builder/scripts/sn_to_jsm.py \
  --input export.xml --site ... --token ... --dry-run

# Skip workflow prompt (for CI/scripted runs)
python3 ~/.rovodev/skills/jsm-workflow-builder/scripts/sn_to_jsm.py \
  --input export.xml --site ... --token ... --skip-workflow-check
```

## ⚠️ Known API Limitations (Jira Cloud)

| Capability | Via API | Via UI |
|-----------|---------|--------|
| Request types | ✅ Automatic | — |
| Custom fields | ✅ Automatic | — |
| Workflow statuses/transitions | ❌ Not supported | ✅ Script generates guide |
| Automation rules | ❌ Browser auth only | ✅ Script generates import JSON |

> **Note:** Jira Cloud REST API does not support creating workflows or importing automations programmatically (as of build 100292). The script generates precise UI guides and import-ready JSON files for both.

## 🏛️ FedRAMP / GovCloud Usage

This tool is safe for use during JSM implementation engagements:
- Scripts run **locally on the PS consultant's machine**
- Only outbound HTTPS API calls to the customer's AGC instance
- No customer data stored or transmitted to third parties
- API token should be **revoked after migration** completes

See `references/fedramp-guide.md` for the full FedRAMP engagement checklist.

## 🔧 Supported ServiceNow XML Types

| XML Type | Detection | Extracted |
|----------|-----------|-----------|
| Flow Designer Export | `sys_hub_flow` tags | Triggers, steps, approvals, notifications |
| Update Set | `sys_remote_update_set` | Metadata, scope info |
| Catalog Item | `sc_cat_item` | Variables, categories, workflows |
| Legacy Workflow | `wf_workflow` | Activities, transitions, conditions |
